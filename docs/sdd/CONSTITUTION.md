7. **Cross-repo hygiene** — reelsynth scripts/artifacts + denoise-opt-meta paper; CHANGELOG when user-visible; mirror README points at current paper version.
8. **Prose honesty** — no em-dash / semicolon-stack / “crush” slop; **repair operator** (not bake cell) in manuscript prose; modest integrative claims.
