\section{Tooling and AI use}
\label{sec:tooling}

\paragraph{Literature discovery.}
Open literature was gathered with the Klaut Research Gateway (local OpenAlex / Crossref / arXiv providers) under queries spanning virtual-analog anti-aliasing, unsupervised restoration, HPO/PBT, RL--GA hybrids for NAS, and audio denoise architectures.
Source PDFs were downloaded for every bibliography entry (\texttt{artifacts/literature\_oa/pdfs/}).
Paywalled-only items were dropped or replaced.

\paragraph{Paper drafting.}
Section planning and revision passes used Klaut \texttt{research\_paper\_*} tools with local Ollama when available.
AI drafts were scaffolding only.
Claims, numbers, and citations were checked against harvest records, PDF analyses, and measured artifacts.
Final prose was edited for DSP terminology and to cut generic filler.

\paragraph{Where AI was not used.}
Model fitting, residual scoring, DualCosine baselines, hybrid GPU search, and inference benchmarks are conventional code (Rust / PyTorch) with deterministic logs and JSON artifacts.
AI did not invent experimental numbers.

\paragraph{Other tools.}
Rust/\texttt{cargo} for the procedural bench. PyTorch CUDA for hybrid GA--PPO search. matplotlib for figures. MiKTeX \texttt{pdflatex} for PDF builds. GitHub for versioned papers and artifacts.
Audible demos: \texttt{reelsynth/brand/artifacts/meta\_approach\_compare/hear\_samples/}.
Vibrato spectrograms: \texttt{scripts/bench\_vibrato\_spectrogram.py}.
