\section{Limitations}
\label{sec:limitations}

We collect honesty notes here rather than repeating them through Results and Discussion.

\begin{itemize}
  \item \textbf{Not a perceptual score.}
    $R_{\mathrm{blend}}$ and $J$ use a procedural no-cliff sibling for seams and an engine-identity prior for the mid-cycle body.
    They do not measure listening quality.
    No formal MOS or MUSHRA was run.
    Downloadable WAVs and vibrato spectrograms support informal A/B only (Section~\ref{sec:listening-protocol}).
    PESQ and STOI are excluded: primary cycles are non-speech wavetable tiles.
    We do not invent THD+N tables.
    Secondary SNR/SDR already appear on some strata boards (e.g.\ Tables~\ref{tab:sota-main},~\ref{tab:va-seam-blep}).
  \item \textbf{Metric lock.}
    Primary holdout claims use the locked v10.1 $R_{\mathrm{blend}}$ protocol
    (Table~\ref{tab:n2n-vs-ours} and Section~\ref{sec:residual-score}).
    Whole-curve prolonged $R$ near $0.991$ (including the historical freeze $R{\approx}0.99093$ vs Dual Cosine ${\approx}0.81658$)
    is a superseded debug score and must not overwrite that holdout reading.
    Separately, the hybrid-only FitCell-to-convergence campaign reports locked $R_{\mathrm{blend}}$ under a longer FitCell budget
    (Section~\ref{sec:v14-converge}); that $0.9912$ figure is \emph{not} the superseded whole-curve metric.
  \item \textbf{Multi-seed protocol.}
    Holdout tables report mean$\pm$std over five evaluation seeds
    (\texttt{20260719}--\texttt{20260723}).
    Matched-$5$k outer-loop re-search under $R_{\mathrm{blend}}$ is complete across three search seeds
    (\texttt{1902771841}, \texttt{2026072701}, \texttt{2026072702}; Table~\ref{tab:meta-approaches}).
    Only one of three hybrid seeds clears the frozen Noise2Noise gate under short FitCell.
    The hybrid-only FitCell-to-convergence follow-up reports the full $750$-evaluation run on seed \texttt{1902771841}
    (Table~\ref{tab:v14-hybrid-converge}).
    Sign tests / win-rates on multi-family boards use paired per-family scores.
  \item \textbf{Domain Noise2Noise vs transfer depth.}
    Domain-trained Noise2Noise quality \emph{was} run on the seven wrap-protocol stress-test boards
    (Table~\ref{tab:transfer-main}). It trails Ours on every column under $R_{\mathrm{blend}}$.
    Latency timings in Appendix~\ref{app:supplement} still use the wavetable checkpoint zero-shot.
    Cycle-GAN / BeatDiff / real KIT--PMU / MOS remain incomplete where noted
    (Table~\ref{tab:transfer-sota-status}).
  \item \textbf{Domain shift on exports.}
    On Factory+FX / Rust tiles the meta favorite can trail no-bake or FIR while still beating Dual Cosine.
    We do not claim universal factory superiority.
  \item \textbf{Search geometry.}
    Search scores Python generator draws.
    The Python multi-family matrix is primary. Rust export is secondary.
    Per-trial width is capped. Demucs-/diffusion-scale stacks were screened out.
  \item \textbf{No wrap-closure theorems.}
    Endpoint-pin can zero wrap-jump while residual falls.
    We claim tiled residual repair toward $r^{\star}$, not endpoint closure or search convergence.
  \item \textbf{Transfer scope.}
    Sci/eng wrap transfer is a classical-board stress test of the wrap protocol, not deep CWRU/ECG SOTA
    (Table~\ref{tab:transfer-sota-status}).
  \item \textbf{Hyperparameter probe.}
    The $\pm 50\%$ one-at-a-time probe (Appendix~\ref{app:supplement}) is not a full re-search of Table~\ref{tab:hyperparams}.
\end{itemize}

\subsection{Future work}
\label{sec:outlook}

A follow-up can treat which sounds fail as the primary object: stratified residual heatmaps over procedural families, cliff-size conditioning, and family-specialist operators under the same outer loop.
Formal listening (even a small author-plus-colleague preference note on high-wrap tiles) remains the clearest missing perceptual check.
